Publicar Grátis no GitHub Pages

Siga o passo a passo abaixo para publicar este quiz na internet sem pagar nada e gerar um link direto para o celular do Oli!

Passo 1: Criar uma conta no GitHub

Acesse github.com e crie uma conta gratuita (caso ainda não tenha).

Passo 2: Criar um Repositório

  • Clique no botão verde "New" (Novo repositório).
  • Nomeie como quiz-biblico-oli.
  • Deixe marcado como Public (Público).
  • Clique em "Create repository".

Passo 3: Enviar este arquivo index.html

  • Na tela do repositório, clique no link "uploading an existing file".
  • Arraste este arquivo index.html e a imagem Code_Generated_Image.jfif para lá.
  • Clique no botão verde "Commit changes".

Passo 4: Ativar o GitHub Pages

  • Clique na aba Settings (Configurações) do seu repositório.
  • No menu à esquerda, clique em Pages.
  • Em Branch, mude de None para main (ou master).
  • Clique em Save.
🎉

Pronto! Em 1 ou 2 minutos seu link estará no ar! Exemplo:
https://seu-usuario.github.io/quiz-biblico-oli
